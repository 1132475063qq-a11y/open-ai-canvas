# 十种故事类型：项目化引擎卡

这些是结构压力，不是套公式、市场预测或对具体作品的复制许可。每类都必须落实为角色选择和后果。

| 类型 | 最小引擎 | 必须压力 | 常见失效 |
|---|---|---|---|
| 屋里有怪物 / Monster in the House | 封闭系统中的威胁 | 逃不掉、怪物/威胁、代价或旧错 | 威胁可轻易离开、只有追逐没有选择 |
| 金羊毛 / Golden Fleece | 任务/旅程改变完成者 | 目标、同行关系、路途使人改变 | 事件只堆景点，任务与人物无关 |
| 愿望成真 / Out of the Bottle | 得到幻想后被迫学习 | 被压抑者、愿望机制、代价/教训 | 愿望只是外挂，主角没有选择 |
| 陷入困境 / Dude with a Problem | 普通人被异常困境压迫 | 平凡视角、巨大困境、自我战胜 | 主角像全能专家，危险不可感 |
| 人生变迁 / Rites of Passage | 无法躲开的生命变化 | 内在否认、外部压力、接受或重建 | 只换事件不改变认识 |
| 伙伴情谊 / Buddy Love | 两人关系迫使彼此改变 | 互相需要、冲突、分离危机、重连 | 关系没有双向影响 |
| 推理调查 / Whydunit | 发现“为什么”与人性阴影 | 罪/谜、调查视角、主题性揭露 | 只揭谁做的，动机没有意义 |
| 傻瓜获胜 / Fool Triumphant | 被低估者暴露体制/强者的荒谬 | 无人信任、强大对手、坚持品质 | 主角只是运气好，体制不受触动 |
| 体制之下 / Institutionalized | 群体吞噬个人，外来者照见规则 | 体制、集体压力、揭露者、代价 | 只有坏人没有系统性规则 |
| 超级英雄 / Superhero | 异常者在普通世界承受误解并作选择 | 天赋/差异、痛苦、服务或代价 | 只有能力展示，缺少人性代价 |

每一类都可以是喜剧、惊悚、爱情、科幻或写实。题材不是类型引擎。
