# Acting Master Profile

A recurring character gets one stable master profile (target 150–220 English words in the source method). It records physique/posture as biography, psychological engine, fixed voice-profile reference, triggered tics, concealment behavior, facade/crack condition, gait, eye life and optionally one softening target.

Rules: observable behavior only; every tic has a trigger; no wardrobe, camera or color; the profile survives costume changes; scene work rewrites the profile instead of pasting it verbatim.
