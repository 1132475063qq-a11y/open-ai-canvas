# TVC 参考：十阶段策划与制作交接

## 原则

十阶段是交付与门禁模型，不是单一 Agent 的越权清单。`tvc_creative_director` 负责阶段 1–3 的主导和品牌复核；后续阶段由对应专业 Agent 负责，`film_project_lead` 管理版本、依赖与 Human 决定。

| 阶段 | 主责任域 | 最低交付 | 进入下一阶段的条件 |
|---|---|---|---|
| 1. 客户 Brief 与产品资料 | tvc | 事实台账、来源、缺口、禁区 | 事实/暂定/冲突分离 |
| 2. 广告策略 | tvc | 受众张力、SMP、RTB、传播矛盾 | 不把愿望写成产品事实 |
| 3. 创意方向 | tvc | 至少三种机制不同的方向、评分、硬门槛 | Human 选择或保留 DRAFT |
| 4. 视觉世界观 | visual + tvc | 视觉命题、品牌可见性原则、风格风险 | 不替代角色/场景 Bible |
| 5. 初步资产规划 | visual / scene / sound | 产品、人物、场景、道具、声音资产清单 | 每项有所有者和测试需求 |
| 6. 广告剧本与复核 | screenwriter + tvc | TVC 剧本、品牌偏差报告 | 故事不违背锁定 Brief |
| 7. 分镜设计 | director-storyboard | 分镜总表、逐镜制作卡、露出/CTA 时机 | 可见事实与空间连续性明确 |
| 8. AI 制作评估与提示词 | feasibility + ai-video-shot-prompt | 风险矩阵、测试顺序、独立镜头 Prompt | 不把提示词当生成结果 |
| 9. 声音设计 | sound-design | 声音/对白/音乐/静默方案 | 不以声音推导角色外形 |
| 10. 后期与交付 | quality_control_editor + lead | 审查、交付矩阵、复检记录 | 无媒体不得声明 PASS |

## 执行模式

- 标准模式：逐阶段门禁推进，适用于正式项目。
- 快速模式：只输出用户指定阶段；必须说明未执行的上游/下游阶段。
- 单项模式：只处理一个问题，不把它误记为项目批准。
- 完整输出模式：可以生成完整草案包，但任何 Human 决定、LOCKED 状态和媒体执行仍需独立证据。

## 创意方向评分与硬门槛

每个方向分别记录受众相关性、品牌可见性、单一核心信息清晰度、戏剧机制/记忆点、执行可行性和原创性风险。评分只辅助比较，不能覆盖硬门槛：产品事实无来源、违反禁区、CTA 不可定位、合规/授权风险未处理、超出明确范围、或核心创意未获 Human 决定时，不得推荐为可锁定方向。

## 变更规则

改变事实、SMP、RTB、核心创意、品牌露出、CTA、范围、预算、时长、已锁定资产或正式剧本时，先输出影响单：变化、原因、受影响 Artifact/镜头、风险、可选方案、推荐、需要批准人和恢复位置。LOCKED 对象必须关联 `CHANGE-REQUEST` 后创建新 object_version；不得原地改写。
